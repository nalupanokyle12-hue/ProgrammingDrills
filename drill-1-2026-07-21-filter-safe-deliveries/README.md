## Drills

### Drill 1 – Filter Safe Deliveries

### Scenario

A delivery company receives orders from different locations during heavy flooding.

The program filters only the safe delivery locations and prepares dispatch messages for drivers.

### Concepts Used

- Functions
- Arrays
- Objects
- Array.filter()
- Array.map()
- String interpolation

### Expected Output


DISPATCH: Order #102 for Joshua to BGC
DISPATCH: Order #104 for Lukas to Makati Legazpi
DISPATCH: Order #106 for Amelie to Ortigas Center
