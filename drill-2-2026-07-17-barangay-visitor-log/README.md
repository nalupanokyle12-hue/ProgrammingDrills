# Barangay Visitor Log

## 📖 Description

This is a simple Python program that records visitors entering a barangay office. It demonstrates modular programming by separating user input, display logic, and program execution into different files.

---

## 💻 Features

- Register visitor information
- Store multiple visitor records
- Display all recorded visitors
- Count the total number of visitors

---

## 🛠️ Technologies Used

- Python 3

---

## 📂 Program Structure

- **main.py** – Runs the program
- **visitor.py** – Registers visitor information
- **display.py** – Displays all visitor records

---

## ▶️ How to Run

```bash
python main.py
```
