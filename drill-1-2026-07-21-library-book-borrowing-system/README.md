## Drill 1 – Library Book Borrowing System

### Scenario

A school library needs a simple system to manage book borrowing and returning.

The activity demonstrates the Model and View concept by separating data storage from program logic.

---

## Program Features

- Display all books
- Borrow a book
- Return a book
- Show available books
- Show borrowed books
- Menu-driven interface

---

## File Description

### models.py

Stores all book information including:

- Book title
- Author
- Borrow status
- Borrower's name

### views.py

Contains the program logic including:

- Menu
- Functions
- Borrowing process
- Returning process
- Displaying books

---

- Python 3
